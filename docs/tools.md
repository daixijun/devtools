# 工具使用指南

本文档介绍开发者工具箱中每个工具的具体用法。工具的分类和顺序与应用内注册表（`src/tools/registry.ts`）保持一致。

- 相关文档：[README_ZH.md](../README_ZH.md)（项目总览）

## 快速上手

- **呼出主窗口**：按全局快捷键呼出 Spotlight 搜索条（macOS 默认 `Option+Space`，Windows/Linux 默认 `Alt+Space`），再次按下隐藏。
- **搜索与打开**：输入名称、描述或关键字过滤工具，`↑`/`↓` 选择、`Enter` 打开；每个工具在独立窗口中运行，`Esc` 逐级退出并隐藏窗口。
- **修改快捷键**：在「设置 → 快捷键」点击"修改"进入录制模式（须包含 Ctrl/Alt/Option/Cmd 修饰键），冲突时会提示。
- **通用操作**：大多数输出框支持一键复制（显示"已复制 ✓"）；文件输入支持点击选择或拖拽；主题在「设置 → 外观」中切换并跨窗口实时同步。

## 编码/解码工具

### Base64 编解码

纯前端实现，输入实时转换（200ms 防抖）。

1. 选择"编码"或"解码"模式；
2. 输入文本或上传文件，输出自动生成；
3. 「交换」可互换输入/输出并切换模式。

解码前会校验 Base64 格式，非法输入直接在输出区提示；显示输入/输出长度，结果可一键复制。

### URL 编解码

最简单的工具：点击「编码」/「解码」按钮做百分号编码转换（`encodeURIComponent`/`decodeURIComponent`），「交换」同时切换模式。解码出错时显示错误说明。

### AES 加密/解密

纯前端实现（CryptoJS），"加密/解密"双标签页。

- **模式**：CBC / ECB / CFB / OFB / CTR；**密钥长度**：128 / 192 / 256 位；**填充**：PKCS#7、ISO/IEC 9797-1、ANSI X9.23、ISO 10126、Zero、No Padding。
- 非 ECB 模式需要 16 字符 IV，可点「随机生成 IV」；密钥/IV 长度不足时给出提示（密钥长度 = 密钥位数 ÷ 8 字符）。
- 解密失败时请检查密钥、IV 与密文是否匹配。

### MD5 加密

三个标签页：**文本加密**（输入即计算）、**文件加密**（选择文件自动计算）、**批量加密**（多选文件生成表格，含状态列）。批量结果支持「复制全部」（`文件名: md5` 格式）和「导出结果」保存为 `.txt`。

### SHA 哈希加密

与 MD5 工具同构（文本/文件/批量三标签页），算法可选 SHA-1/224/256/384/512 和 SHA-3，默认 SHA-256；切换算法后所有结果自动重算。

### JWT 生成

纯前端签名（jsrsasign）。

1. 编辑 Header（切换 `alg`）与 Payload（双 Monaco 编辑器，带 JSON 校验）；
2. 设置有效期（秒），自动写入 `iat`/`exp`；
3. HS* 算法填写 Secret Key；RS* 算法上传 RSA 私钥（`.pem`/`.key`，带格式校验）。

生成的 JWT 只读展示，可复制。

### JWT 解码

粘贴 Token 实时解析（300ms 防抖），展示美化后的 Header/Payload（分别可复制）与签名，自动识别算法。

**签名验证**：HS* 算法输入 Secret Key；RS* 算法上传 RSA 公钥（`.pem`/`.key`/`.pub`）。显示验证成功/失败。注意：客户端验证仅用于调试，生产环境请在服务端校验。

### 密码生成器

使用 `crypto.getRandomValues` 生成密码（进入页面自动生成一次）。

- 长度滑块 4–64（默认 16）；字符类型：大写 / 小写 / 数字 / 特殊符号；
- 特殊符号提供 6 组预设快速选择（常用/括号/标点/数学/货币/其他）和自定义字符输入；
- 显示强度评级（弱/中等/强/非常强）及评级依据；一键复制、重置选项。

### 密码加密验证

"加密/验证"双标签页，纯前端实现（bcryptjs + CryptoJS）。

- **算法**：bcrypt（推荐，轮数 4–20，默认 10）、PBKDF2（迭代 1,000–1,000,000，默认 10,000）、SHA-256、SHA-512、MD5（已标注不安全，仅用于兼容场景）；
- **验证页**：输入密码 + 哈希 + 算法，输出验证成功/失败。

### RSA 密钥对生成

通过后端命令生成，支持 2048（推荐）/3072/4096 位，可填 OpenSSH 注释（如 `user@host`）。

- **私钥**：PKCS#8 / PKCS#1 标签切换；
- **公钥**：PEM (SPKI) / PKCS#1 / OpenSSH 标签切换（OpenSSH 格式可直接粘贴进 `authorized_keys`）；
- 每种格式均可复制或下载对应扩展名文件；注意私钥切勿泄露或提交到仓库。

## 证书工具

### 证书查看器

粘贴 PEM 文本或上传证书文件（自动识别 PEM/PFX），由后端解析整条证书链。

- 按链级别（终端证书/中间 CA/根 CA）分标签查看详细信息、有效期（过期红色警告，显示剩余天数）；
- **链完整性检查**：不完整时给出 CA 证书下载建议；
- **顺序检测**：按部署规范（终端在前、根在后）比对当前顺序，错误时以红/绿对比展示，并提供「复制正确顺序的证书」一键修正。

### CSR 查看

粘贴或上传 CSR（自动识别 PEM/DER），由后端解析：版本、Subject 各字段、公钥（类型/长度/曲线/SPKI/SHA-256 指纹）、签名算法、请求扩展（含 critical 标记）。

可选粘贴配套私钥做**匹配校验**（指纹比对，显示是否匹配）。

### CSR 生成

表单式生成 PKCS#10 CSR，由后端生成密钥对并签发请求。

- **主题**：CN（必填）、C/ST/L/O/OU、邮箱；
- **密钥**：RSA（2048/3072/4096）或 ECC（P-256/P-384/P-521）；
- **SAN**：每行一个备用域名/IP。

输出 CSR、私钥、公钥三张卡片，均支持复制与下载（文件名按 CN 自动安全化）。

### PEM 转 PFX

1. 粘贴/上传 PEM 证书，自动识别证书段并尝试提取内嵌私钥（支持 RSA/EC/PKCS#8 头）；
2. 设置 PFX 密码（必填）；私钥本身被加密时需再填私钥密码；
3. 转换后保存 `.pfx` 文件。

底部提供等效 OpenSSL 命令参考。

### PFX 转 PEM

上传 `.pfx`/`.p12` 文件并输入密码（可为空），输出包含证书与私钥的合并 PEM，可复制或下载。错误信息按类型翻译（密码错误/格式错误/未找到证书），底部同样有 OpenSSL 命令参考。

### 在线 SSL 检测

输入域名在线检测（需要网络），结果分 6 个标签页：

- **概览**：域名/服务器 IP/服务器版本、安全评分（x/100）、SSL Labs 等级、HTTP/2 与 ALPN 支持；
- **证书信息 / 证书链**：各级证书详情、链完整性、信任锚与校验错误；
- **加密套件**：协议支持与服务器套件顺序；
- **CVE 漏洞**：按严重级别（CRITICAL/HIGH/MEDIUM/LOW）筛选；
- **安全评估**：证书/协议/密钥交换/加密强度分项评分与加固建议。

最近检测的域名（最多 10 个）本地保存，可点击重查。

## 网络工具

### 子网掩码计算器

纯前端计算。输入 IP/CIDR（如 `192.168.1.0/24`）或"IP + 子网掩码"，版本可选 auto/IPv4/IPv6。

- IPv4 输出：CIDR、掩码、网络/广播地址、首末可用 IP、总 IP 数与可用数；
- IPv6 输出：前缀、网络位/主机位、完整展开格式、网络地址。

### IP 地址信息查询

留空直接查询本机 IP，或输入任意 IPv4/IPv6 查询（前端正则校验格式）。多数据源结果按来源分组展示：IP、国家/地区、城市、运营商、时区。「显示原始 JSON」可查看完整响应。打开页面时自动查询当前 IP。

### DNS 解析工具

"正向解析 / 反向解析"双标签页，全部由后端执行查询。

- **正向解析**：DNS 服务器多选（内置预设列表，可添加自定义服务器如 `9.9.9.9`），同时向多台服务器并发查询并对比结果；记录类型可选 ALL/A/AAAA/MX/TXT/CNAME/NS/SOA；
- **反向解析**：单个 IP 查 PTR 记录；批量模式每行一个 IP 批量查询。

### 域名 Whois 查询

支持批量：域名以空格/逗号/换行分隔（自动去重），显示"开始查询 (N)"。

- **数据源**：auto（优先 RDAP 结构化数据，自动回退传统 Whois）或指定渠道（verisign/cndns/hichina）；按渠道 700ms 频率限制；
- **结果**：注册商、注册人、创建/过期/更新时间、状态、NS 服务器，带进度统计（完成/成功/平均耗时）；
- 24 小时结果缓存 + 最近 200 条查询历史（可清空）；支持导出 CSV 与 JSON 文件。

## 数据格式转换

### JSON 格式化

单个 Monaco 编辑器内原位替换：格式化（2 空格美化）、压缩、**去除转义**（解析被转义的 JSON 字符串）、复制、长度统计。无效 JSON 顶部红色错误条提示。

### 格式转换器

JSON / YAML / TOML 互转（纯前端，js-yaml + smol-toml）：输入与输出格式独立选择，双 Monaco 编辑器并排实时转换。输入输出格式相同时报错提示。

### JSON 转 Go 结构体

粘贴 JSON 自动生成（500ms 防抖），双编辑器分栏。

- 选项：结构体名称（默认 `AutoGenerated`）、导出字段、Go 1.18+（`any`）、Go 1.24+（`omitzero`）；
- 标签多选：json / yaml / gorm / db / sql / toml / env / ini（json 默认选中）。

### SQL 转 Go 结构体

粘贴 `CREATE TABLE` 语句自动生成，支持多表与多种方言。

- 选项：复数表名单数化、导出字段、Go 1.24+、JSON 标签处理（无/`omitempty`/`omitzero`）、标签多选（json+gorm 默认选中）；
- 多表时输出区按表名分标签页；编辑器主题跟随应用深浅色。

### SQL 转 Go Ent ORM

粘贴 SQL DDL 自动生成 Ent Schema（多表分标签输出）。

- 选项：复数表名、生成边缘关系（edges）、Mixin、Hooks、Policy、UUID 主键、软删除、包名（默认 `schema`）。

> SQL 工具基于 sqlparser AST 解析，支持 MySQL 反引号、无符号类型（uint8–uint64）、复杂复数表名（如 `pipelines` → `Pipeline`）与 Generic/MySQL/PostgreSQL/SQLite 方言。

## 媒体格式转换

### 图片格式转换

多选文件或选文件夹批量转换，由后端处理。

- **目标格式**：JPG/JPEG/PNG/GIF/BMP/TIFF/WebP/ICO/HEIC；源格式可 auto 自动检测；
- **选项**：质量（默认 85）、尺寸调整（按宽/按高/按宽高）、移除 EXIF、转换后删除源文件、自定义输出目录；
- 文件列表悬停 EXIF 单元格可查看拍摄信息（相机型号、曝光、ISO、焦距等）；逐文件显示进度与状态。

### 图片预览器

纯前端预览：支持输入图片 URL、data: URL，或直接 `Ctrl/Cmd+V` 粘贴图片。

- **操作**：滚轮以光标为中心缩放、拖拽平移、双击缩放、全屏（Esc 退出）；
- 显示宽高/格式/大小；支持**另存为** PNG/JPEG/GIF/WebP（带质量滑块，canvas 导出）。

### 视频格式转换

调用系统 FFmpeg（**需本机安装**：macOS `brew install ffmpeg`、Windows 下载加入 PATH、Linux `apt/dnf install ffmpeg`）。启动时自动检测，未安装时禁止选择文件并给出安装引导。

- **目标格式**：MP4/MOV/AVI/MKV/WMV/FLV/WebM/M4V/3GP/MPEG；源格式可 auto；
- 多选文件或选文件夹批量；可删除源文件、自定义输出目录；
- 列表显示时长、分辨率、转换进度与状态。

### 图片压缩工具

单张（文件对话框）或整文件夹批量，由后端处理。

- **压缩模式**：无损优化（PNG 走 oxipng+zopfli 真无损，JPEG 最高质量重编码）或质量压缩（PNG 调色板量化，类似 TinyPNG；JPEG/WebP 降质量），质量滑块 1–100%；
- **选项**：PNG 无损优化级别、等比缩放（最大宽/高，可只填一项）、移除 EXIF、输出格式（保持原格式/PNG/JPEG/WebP）；
- 单张压缩后可打开**压缩前后对比**弹窗：滑块拖动对比画质，显示压缩率与前后体积；批量列表带缩略图与压缩率统计。

## 开发工具

### 正则表达式测试器

由后端执行匹配（300ms 防抖实时校验合法性）。

- **引擎**：rust / re2 / pcre / golang / javascript 共 5 种可选；
- **模式**：测试 / 替换（替换可选第一个或全部）；
- **标志**：忽略大小写、多行、点号匹配换行、交换贪婪、Unicode（默认开）；
- **结果**：匹配详情列表（内容、位置区间、捕获组、命名组）+ 原文黄色高亮全部匹配。

## 时间工具

### 时间戳转换

双向转换：「时间戳 → 日期时间」或「日期时间 → 时间戳」（下拉切换）。

- 时区下拉覆盖全部 IANA 时区（默认 Asia/Shanghai）；「毫秒单位」开关切换秒/毫秒；
- 实时时钟（每秒刷新，同时显示秒级与毫秒级时间戳），「当前时间」一键填入。

## 设置

- **外观**：浅色 / 深色 / 跟随系统，跨窗口实时生效；
- **系统**：显示托盘图标、开机自动启动、启动时最小化到托盘、关闭时最小化到托盘（后两项依赖托盘开启）；
- **快捷键**：查看/修改呼出主窗口的全局快捷键（录制时须含修饰键，10 秒超时，冲突时提示）；
- **关于**：应用名称、版本与技术栈信息。
